01 / PROBLEM

Make procurement progress visible.

Manual purchase-request follow-up creates fragmented visibility across request creation, assignment, processing and PO conversion. Teams need a clear view of ownership, status and the requests that need attention.

02 / SOLUTION

Connect operational work with analytics.

I built a full-stack Flask application that centralizes the PR lifecycle and combines structured workflow with operational analytics. This independently authored public demo lets visitors explore the process with fictional records and their own resettable session.

06 / WORKFLOW INTELLIGENCE

Keep every update in context.

Assignment and controlled status transitions establish ownership and progress. Timeline history, preset notes and editable estimates keep the request’s context visible. Linking a PO captures the request lines and sets its status to PO Issued.

Filters and search update both the register and analytics. Sorting changes the order, while pagination keeps the register manageable. Reset returns the visitor to the deterministic baseline.

07 / REPORTING

A report that matches the view.

Download deterministic XLSX reports for the complete filtered scope across all pages. Three sheets cover the request dashboard, request items and PO summary, with estimates and PO totals aligned to the same records.

Identical logical state produces byte-identical workbooks. Reports are generated in memory and contain only synthetic data.
